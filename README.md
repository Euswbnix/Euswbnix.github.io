# Alex H. — Portfolio

Personal portfolio site, live at [huangjiz.com](https://huangjiz.com).

## Stack

- Vanilla HTML / CSS / JavaScript — no frameworks
- [Three.js](https://threejs.org/) — interactive Earth globe and skill orbs
- [VanillaTilt.js](https://micku7zu.github.io/vanilla-tilt.js/) — card hover effect (desktop only)
- Hosted on GitHub Pages with a custom domain

## Structure

```
index.html   — all markup and JS
styles.css   — all styles
images/      — static assets
CNAME        — custom domain config
```

## Sections

1. **Hero** — animated Earth globe, typewriter tagline
2. **About** — bio, skills, experience cards
3. **Education** — degree timeline
4. **Projects** — project cards with stack tags
5. **Skills** — interactive 3D skill orbs
6. **Life** — personal section
7. **Contact** — Live Decode panel + contact card
